## Seuils figés (R-PIVOT-01) — NE PAS MODIFIER APRÈS RÉSULTATS

### Condition 1 : P1 vs P2 (Vote majoritaire vs ETAU/SECS complet)
- **Detection Recall** : P1 ≥ P2 - 10pp (différence ≤ 10 points pourcentage)
- **Localization Precision** : P1 ≥ P2 - 10pp
- **Cost per Detection** : P1 ≤ 0.7 × P2 (30% moins cher)
- **Test statistique** : McNemar p<0.05 sur 5 cycles
- **Résultat** : Si TOUTES 3 remplies → PIVOT vers P1 (ETAU/SECS = option traçabilité)

### Condition 2 : P3 vs P4 (Allégé vs Complet)
- **Detection Recall** : |P3 - P4| < 5pp
- **Localization Precision** : |P3 - P4| < 5pp
- **Test statistique** : McNemar p≥0.05 (non significatif)
- **Résultat** : Si remplies → granularité fine = raffinement non prioritaire, P3 devient référence

### Condition 3 : Justification P2/P4 tel quel
- **Seul écart significatif** sur **Recall ET Precision** simultanément (p<0.05, ≥10pp)
- Pas juste sur l'un des deux
- Pas juste sur coût

### Seuils statistiques (R-STAT-01, R-STAT-02)
- N = 5 cycles minimum
- IQR sur 5 cycles < 30% de la médiane → N=5 accepté
- IQR ≥ 30% → étendre à N=10 cycles
- Barres d'erreur = IQR sur tous graphiques
